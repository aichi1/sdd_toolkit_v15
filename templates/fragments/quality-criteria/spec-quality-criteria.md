# 仕様の品質基準（`/spec-check` のチェックリスト）

> 機械検査できる項目は `scripts/spec_check.py` が見る。本ファイルは**目視でしか見えない項目**を扱う。
> 出典: sdd-toolkit-v15 Phase 07（R-14）。

## A. 存在するものだけを参照しているか（機械検査あり）

- [ ] 仕様が参照するスラッシュコマンドが `.claude/commands/` または `.claude/skills/<name>/SKILL.md` に実在する
      （Claude Code 2.1 以降、両者はどちらも `/<name>` を作り同じように動作する。sdd-toolkit-v15 C-28）
- [ ] 仕様が参照するファイルパスが実在する
- [ ] 実在しないものを参照している場合、**`docs/spec-check-allowlist.json` に `reason` 付きで登録されている**
- [ ] 許可リストのエントリの `scope` が**必要最小限のパス**である（`"*"` は検出能力を失わせうる）
- [ ] 前方参照のエントリが、**実物を作った時点で削除されている**

> **抑制手段は許可リストだけである。** 文書中に「まだ存在しない」と宣言しても報告は消えない。
> 当初は「同じ行の否定語」「文書冒頭の宣言」などのヒューリスティックで抑制していたが、
> **3 巡・Critical 10 件**にわたって回避経路が生まれ続けたため、オーナー決定（2026-09-05）で全廃した。
> 現在この抑制が効かないことは `scripts/test_spec_check.py` の `TestNoHeuristicBypass` が固定している。

> **実績**: このツールキット自身で 2 回起きた。
> **C-19** —— `/recap` が存在しないのにセッション運用の手順に書かれていた。
> **C-38** —— `/agents` ウィザードが削除された後も D-01 の手順に残っていた。
> どちらも**実行して初めて判明**した。

## B. 判定できる形で書かれているか（目視）

- [ ] 各成功条件に**判定方法**がある（「何をもって満たしたとするか」）
- [ ] 判定方法が**コマンド**で書かれている場合、そのコマンドが実行できる
- [ ] 「適切に」「必要に応じて」「十分な」など、**判断基準のない語**を使っていない
- [ ] 数値の上限・下限に**根拠**があるか、**暫定値である旨**が書かれている

> **実績**: Phase 04 の上限値（ターン 60 / 連続失敗 3 / 再試行 2）は暫定値であり、
> `change-report.md` に「実測の裏づけがない」と明記した。
> 暫定値を暫定値と書かないと、後のフェーズが根拠として引いてしまう。

## C. 範囲が判定できるか（目視）

- [ ] スコープ内・外の境界が判定できる
- [ ] 「基本的には」「原則として」の例外条件が書かれている
- [ ] 非目的（やらないこと）が明示されている

## D. 矛盾がないか（目視）

- [ ] 同じ事項について相反する 2 つの記述がない
- [ ] 要件と成功条件が整合している
- [ ] 上位文書（constitution 等）と矛盾していない

> **実績**: Phase 06 で「第10条の条文は遡及適用しないと明言しているのに、
> 実装は前フェーズの振る舞いを判定材料にしている」という**条文と実装の食い違い**が
> Validator によって検出された。仕様どうしだけでなく**仕様と実装の整合**も見る。

## E. 強制点があるか（constitution を持つプロジェクトのみ）

- [ ] 各条項に「原則」と「強制点」の両方がある
- [ ] **強制点が実際に実行できるコマンド**で書かれている
- [ ] 強制点を持たない原則が条項になっていない

> **実績**: 「強制点として書いたコマンドが実際には機能しない」失敗が**同型で 4 回**起きた
> （C-26 / C-30 / C-42 / C-47）。**強制点を書いたら、そのフェーズ内で必ず実行して確かめる。**

## F. テストがあるか（目視）

- [ ] 各要件に対応するテストがある
- [ ] **負のテスト**（わざと違反する入力）がある

> **実績**: **C-39** —— 「hooks は例外時にセッションを止めない」という要件が最初から存在したのに、
> テストがなかったため 2 つの hook の違反が長期間見逃されていた。
> **テストのない要件は、無いのと同じ。**
